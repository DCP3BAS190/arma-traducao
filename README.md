# 🇧🇷 Tradução para Arma: Cold War Assault Remastered

Essa tradução foi feita como **hobbie**, nada oficial.  
O objetivo é *“quebrar um galho”* na questão da escassez de traduções para esse jogo.

## Instalação
**OBS: É altamente recomendado fazer um backup!**
1. Baixe o arquivo `.zip` pelo link:  
   [Download via Google Drive](https://drive.google.com/file/d/1YhaQfMN9SRRlwxcj30ow012hSKJYxy3k/view?usp=sharing)
2. Baixe o arquivo `.zip`: **Tradução_Arma_Cold_War_Assault_Remastered_PT-BR**  
3. Extraia o `.zip`: **Tradução_Arma_Cold_War_Assault_Remastered_PT-BR**  
4. Copie/Recorte as pastas **BIN** e **Remastered** e cole no caminho:  
   **C:\Program Files (x86)\Steam\steamapps\common\ARMA Cold War Assault**  
5. Selecione a opção "Substituir o arquivo no destino".

## Desinstalação
- **Via Steam**:  
  1. Clique com o botão direito no jogo na biblioteca.  
  2. Vá em *Propriedades* → *Arquivos locais*.  
  3. Selecione *Verificar integridade dos arquivos*.  
  4. O Steam irá restaurar os arquivos originais, removendo a tradução.  

- **Outros meios**:  
  1. Reinstale o jogo manualmente.  
  2. Ou substitua novamente os arquivos modificados pelos originais (caso tenha feito backup).
